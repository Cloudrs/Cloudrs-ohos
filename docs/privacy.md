# 关于 Cloudrs 与隐私的声明

> 更新日期：2026.06.15
> 生效日期：2026.06.15

Cloudrs 是由 王献（以下简称“我们”）提供的、用于连接您自行搭建或指定的 Cloudreve 私有网盘服务的第三方客户端应用。

**重要说明：我们不运营任何服务器，不收集、不接收、不存储您的任何文件或个人信息。** 您的所有数据仅在“您的设备”与“您自行填写的 Cloudreve 服务器”之间直接传输，服务器的归属、位置与数据保存策略完全由您决定。

## 1. 我们如何处理您的信息

为实现登录与网盘功能，应用会在您的设备本地存储以下信息，且仅保存在本机：

- 服务器地址、登录账号；
- 登录凭据（Cookie、刷新令牌）。我们不保存您的明文登录密码；
- 您账号的公开资料（昵称、头像、用户组等，由您的服务器返回）；
- 相册备份设置、传输（上传/下载）记录。

以上信息均存储于设备本地的加密存储中（SQLite 安全等级 S4 与加密偏好设置），不会上传给我们，也不会用于登录您服务器之外的任何用途。

您上传或下载的文件内容，仅在您的设备与您的服务器之间传输，我们不接触、不留存。

## 2. 设备权限调用

- **网络访问与网络状态**：用于连接您的服务器，并判断当前为 Wi-Fi 或移动网络，以便在“仅 Wi-Fi 备份”开启时决定是否上传；
- **读取图片和视频**：用于在您开启相册自动备份时，读取本地相册并上传到您的服务器；
- **修改/保存图片和视频**：用于将您下载的文件保存到本地相册；
- **生物识别**：用于“应用锁”的本地身份校验。生物特征由系统安全管理，全程不离开您的设备，我们无法获取；
- **隐私窗口**：在“应用锁”开启时防止截屏、录屏及多任务界面泄露内容；
- **剪贴板**：仅用于将分享链接、脱敏后的诊断信息写入剪贴板，我们不会读取您的剪贴板。

## 3. 问题反馈（由您主动发起）

当您使用“问题反馈”功能时，应用会生成一段诊断信息（应用版本、已掩码的服务器地址与账号、用户组、最近的本地日志），并由您选择通过系统邮件或 Gitee 问题页面发送给我们。该信息已做脱敏处理，不包含密码、Cookie、刷新令牌及文件下载直链。是否发送由您决定。

## 4. 第三方共享

本应用不集成任何第三方统计、分析、广告或追踪 SDK，不会与任何第三方共享您的信息或文件。

## 5. 信息存储地点及期限

您的文件与数据存储在您自行配置的 Cloudreve 服务器上，存储地点与期限由您决定。本应用在设备本地保存的信息，会在您退出登录、删除对应账号或卸载应用时被清除。
